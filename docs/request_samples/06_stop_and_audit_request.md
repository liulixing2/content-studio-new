# 停止并审查需求模板

当感觉项目越改越乱、功能被改坏、上下文漂移时，用这个模板。

## 立即停止

```text
停止继续改代码。先审查当前状态。
```

## 我发现的问题

1. 
2. 
3. 

## 需要你审查

- 当前 Git 状态。
- 最近 3 次提交改了什么。
- 是否违反 AGENTS.md。
- 哪些功能可能被破坏。
- 哪些改动应该保留。
- 哪些改动应该回滚或重新做。

## 禁止事项

- 不要继续写新功能。
- 不要大重构。
- 不要调用 DeepSeek。
- 不要联网。
- 不要删除文件，除非我确认。

## 输出格式

请只输出：

1. 当前状态
2. 发现的问题
3. 建议修复顺序
4. 每一步预计影响范围
5. 是否需要我确认
