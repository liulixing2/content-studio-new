## 具体问题

请明确指出哪里不对：

- 是否重复互动？
- 是否追加了默认素材说明？
- 小标题是否空？
- 是否出现模板套话？
- 是否标题和正文不一致？
- 发布检测分数是否不合理？

## 期望规则

```text
例如：如果正文已有“互动话题：”，项目不要再追加“互动引导：”。
```

## 本次边界

```text
例如：只改 Prompt 规则和导入清洗，不改页面布局，不接 DeepSeek API。
```

## 验收标准

- 同类文本再次导入不会出现该问题。
- 测试内容不能通过发布检查。
- 正文不自动保存。
- `npm run build` 和 `manage.py check` 按涉及范围执行。
