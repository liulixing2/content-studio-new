# 需求样本说明

这个目录放给用户复制修改的需求模板。以后给 Codex 提需求时，优先复制对应文件，填完再发送。

推荐原则：

- 先写本次目标。
- 再写当前现象。
- 明确期望结果。
- 写清楚本次边界，哪些不要改。
- 最后写验收标准。

可用模板：

- `01_ui_layout_request.md`：页面布局、交互、视觉调整。
- `02_bug_fix_request.md`：按钮失效、接口失败、保存失败等 bug。
- `03_article_quality_request.md`：公众号 Prompt、正文导入、模板排版、发布检测。
- `04_backend_api_request.md`：后端接口、数据保存、导出、质检服务。
- `05_docs_rules_request.md`：文档、规范、AGENTS.md、开发约束。
- `06_stop_and_audit_request.md`：感觉项目跑偏时，让 Codex 停止并审查。
