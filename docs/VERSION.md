# 版本记录

## 0.1.0-planning

状态：需求整理与公众号框架准备。

日期：2026-08-20

当前范围：

- 已整理三大模块需求。
- 已确认第一阶段只做公众号文章框架。
- 已确认内容生成后先进入临时预览区。
- 已确认用户点击保存后才写入作品库。
- 已确认 DeepSeek 调用必须由用户按钮触发。
- 已确认第一阶段默认 SQLite，不强制 MySQL / Redis。

暂不实现：

- 视频剪辑。
- 小说正文生成。
- 真实 DeepSeek API 调用。
- 图片真实生成。
- FFmpeg 自动剪辑。
- Redis / Celery。
- MySQL。
