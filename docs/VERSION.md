# 版本记录

## 0.2.4-prompt-builder-textarea

状态：DeepSeek 正文 Prompt 工作区。

日期：2026-08-21

已完成：

- 右侧生成区域改为一个可编辑的大 Prompt 输入框。
- 方向、标题、热词、大纲、模板都作为可插入模块进入同一个输入框。
- 复制给 DeepSeek 的内容以大输入框为准，用户可自由修改。
- 删除前端旧的分散式 Prompt 按钮和热点整理残留。
- 模板只保存通用结构规则，不写死具体题材词。
- Prompt 工作区优化为上方需求、下方正文；需求框默认包含标题、方向、大纲、模板和硬性要求。
- 页面舍去右侧工具栏，生成正文移动到中间主栏；辅助设置和作品库收进底部折叠区。

## 0.2.3-publish-template-loop

状态：公众号发布模板闭环。

日期：2026-08-21

已完成：

- 粘贴正文导入时自动识别标题、摘要、小标题、互动引导和素材说明。
- 没有小标题的正文会自动拆成基础公众号段落结构。
- 公众号富文本模板改为内联样式，复制到公众号编辑器更稳定。
- 发布检查允许两段式短文通过，避免把可发布短文误判为半成品。
- 配图建议不再混进复制正文，避免误发布编辑提示。

## 0.1.0-planning

状态：需求整理与公众号框架准备。

日期：2026-08-20

当前范围：

- 已整理三大模块需求。
- 已确认第一阶段只做公众号文章框架。
- 已确认内容生成后先进入临时预览区。

- 图片真实生成。
- FFmpeg 自动剪辑。
- Redis / Celery。
- MySQL。
